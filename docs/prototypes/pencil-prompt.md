## 产品与骨架（已定，勿改信息架构）

- 产品名：漫长游记  
- 整体：**飞书式左栏 + 右侧主内容**（不要整行顶栏）  
- 日记页：**左导航 | 中列表 | 右正文**（Day One 三栏）  
- 「写日记」只在日记中栏顶部（小号次强调按钮）  
- 侧栏顶：圆形头像 + 产品名；hover 邮箱；点击进「我的」  

## 视觉方向（需重新设计到「更合适」）

上一版 HTML 视觉不满意，请在 Pencil 中重做气质，但仍遵守：

1. **大面积底色**：浅米黄 / 便签纸 / 浅色纸张（包容高饱和点缀）  
2. **饱和色只做点缀**：情绪形状、标签、散点、小按钮，不铺整页渐变  
3. **情绪形状签名**：  
   - 平静：厚水波曲线块（顶凹底凸）  
   - 紧张：毛毛球  
   - 低落：扁软泥 / 扁荷包蛋（与水波明显不同）  
   - 喜悦：圆润笑脸 Blob  
4. **能量**：专注度 = 心形；能量消耗 = 闪电（0–5）  
5. 字体：友好圆润标题 + 高可读中文正文  
6. 禁止：整页紫渐变、大块刺眼实心红 CTA、emoji 当正式图标
