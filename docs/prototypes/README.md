# 漫长游记 · 原型说明（B2 · Pencil）

> 高保真以 **Pencil** 为准；`index.html` 为早期 HTML 稿，仅作对照。原型不是生产前端源码。

## 打开方式

在 Cursor 中打开 Pencil 文件：

```text
docs/prototypes/journal_growth.pen
```

设计 brief：`docs/prototypes/pencil-prompt.md`

视口基准：桌面 **1440×900**。

## 页面清单

| 视图 | 说明 |
|------|------|
| 日记工作台 | 飞书式左栏 + 中栏列表 + 右栏正文（可点高亮打开批注浮窗） |
| 自我认知 | 顶横筛话题 + 时间线摘录 |
| ~~情绪图谱~~ | **本期不做**（后置；Frame `05-情绪图谱` 仅存档） |

## 关键组件

- 侧栏顶：圆形头像 + 产品名；hover 邮箱；点击进「我的」
- 中栏：筛选图标 + 小号「写日记」
- 右栏：日期/标题、标签、AI 建议条、正文高亮、能量卡片、小号「保存」
- M01 能量浮窗：专注度♡ / 能量消耗⚡
- M02 话题浮窗：思考类 + 情绪类 chips
- 情绪形状：喜悦圆、平静厚水波、紧张毛毛球、低落扁软泥

## 交互状态（原型已示意）

- 导航 active / hover
- 列表选中
- 高亮点击 → 浮窗
- 象限选中 → 下方切片与观察归属联动
- 头像 hover 浮层

## Mock 数据

- 3 篇示例日记（工作节奏 / 朋友聊天 / 周末空档）
- AI 建议标签：自我认知、疲惫
- 美好时光默认近 10 篇范围内的示例散点与切片
- 账号：`you@mail.com`

## 需要真实 API 的位置

- 登录 / 注册 / 邮箱验证
- 日记 CRUD、划线标记读写
- AI 标签建议（DeepSeek；无 Key 时 Mock）
- 导入解析任务
- 美好时光聚合查询与象限观察 CRUD

## 必须在生产实现的视觉

- 浅米黄纸色 token
- 双模式高亮（能量 vs 话题/情绪）
- 情绪形状三联（水波 / 毛毛球 / 软泥）差异可辨
- 小号次强调按钮（避免大块实心红 CTA）

## 仅原型展示

- 选区工具条未做真实 Selection API（用已有高亮点击代替）
- 导入仅展示第一步上传区
- 窄屏为简化隐藏中栏，生产需做列表↔正文两步切换
